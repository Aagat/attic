SAVE FROM ANYWHERE

A good article is one tap away.

Connect your browser or phone once. Keep reading; Attic will prepare the PDF.

Chromium browser extension

Click the toolbar button to save the current page, or right-click any article link and choose Save link to Attic.

Download extension
  1. Unzip the download.
  2. Open chrome://extensions, enable Developer mode, and select Load unpacked. Choose the unzipped attic folder.
  3. Pin Save to Attic. Click it to connect using the server address below and your Attic access key.

The access key is BEARER_TOKEN in your server configuration. The extension stores it locally in this browser. A ✓ badge confirms that Attic queued the article.

Android · Share to Attic

Install Attic from Chrome, then share a link from another app and choose Attic. Check the shared link and tap Save article.

  1. Open this server’s HTTPS address in Chrome on your phone. Keep Tailscale connected if you use a private Tailscale address.
  2. Use Chrome’s menu → Add to Home screen → Install, or the install button when offered.
  3. Open Attic and sign in once. It can then receive links through Android’s share sheet.

Receiving a share fills in the link; it does not save until you tap Save article. Attic needs a connection to your server to save.

iPhone & iPad · Save to Attic

For your reading library, open Attic in Safari and choose Share → Add to Home Screen. For saving from other apps, use the Shortcut below.

Create a Shortcut named Save to Attic. It submits directly from the share sheet, without opening the library.

  1. In Shortcuts, create a new shortcut. In its details, enable Show in Share Sheet and accept URLs and Safari Web Pages.
  2. Add Get URLs from Input, using Shortcut Input. Then add Get Item from List, choosing First Item.
  3. Add Get Contents of URL with the endpoint below. Expand its options and set Method: POST.
  4. Add the header Authorization with value Bearer YOUR_ATTIC_ACCESS_KEY. Set Request Body: JSON, add a Text field named url, and set its value to the Item from List variable from step 2.
  5. Add Get Dictionary Value for id in the response, then If it has any value → Show Notification “Saved to Attic”; Otherwise → Show Result with the response. This avoids reporting a failed request as saved.

Use your Attic access key, not your ChatGPT credentials. Keep this configured shortcut private: it contains your access key. When iOS asks, allow the shortcut to contact your Attic server.

Then use Share → Save to Attic on an article. No separate mobile app is required.

This setup must be completed in Apple’s Shortcuts app. Android’s installed-web-app share target does not provide an iOS share-sheet entry.
